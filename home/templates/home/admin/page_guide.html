Publishing and language copies

Publish keeps the current publishing behaviour: linked language copies (aliases) are updated and published too, using this page's text until translated. Independent translated pages are edited separately.

To prepare a separate translation, open Status → Switch locales, select the language, then choose “Convert this alias into an ordinary page”. Edit and publish that translation independently.

Page order: header → content before the sections → your sections or automatic lists → content after the sections.
